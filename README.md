# ABStart
一个简单的Spring Boot项目快速开发框架，Demo工程
suite‑kernel

## Road-Map
+ 初始化Spring Boot工程
+ 模块分层
+ 代码生成器、简单增删改查、分页处理、JSR303参数校验
+ 请求日志打印、执行SQL打印、TraceID、操作日志到日志库
+ 接口响应结果统一格式，ResponseAdvice默认包装成固定结构
+ 全局异常捕获、统一异常处理
+ 登录模块：密码盐值、JWT/Session、登录拦截、HttpOnly Cookie
+ 权限：用户角色权限、接口/数据权限、操作权限；避免水平越权、垂直越权
+ 防重放、防爆破、限流
+ 接口加密？
+ 业务日志、错误日志、请求日志分别存储
+ 文件上传、下载
+ 通用能力下层：接口、鉴权
+ smart-doc接口文档生成
+ 文件上传下载；Excel文件上传解析、json导出;
+ 接口缓存、接口Gzip压缩、接口加密、数字签名、验签解签
+ Docker部署
+ jar单独生成到文件夹改造
+ 系统资源监控(OS/version/osArch/CPU逻辑核数量/内存总大小/硬盘占用率/网卡IP/网卡速率/主机启动时间/进程信息/配置信息)
+ 线程池，优雅关闭
+ 操作日志：如何优雅地记录操作日志？https://tech.meituan.com/2021/09/16/operational-logbook.html

## 故障考虑
1. 时间回拨
2. 数据源故障、连接泄露、连接超时、长耗时连接占用
3. 网络断开、网络丢包、网络超时
4. 文件占用、文件(夹)权限、文件目录不存在
5. 未处理异常，三方包内部导致的NPE等记得捕获
